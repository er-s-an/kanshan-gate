## 摘要

看山任意门把盐选故事从「读到这里」变成「我已经走进去了」：一个由刘看山守门的 3D 门厅，连接若干短篇互动世界；玩家玩完带走一张记录「我怎样进去过」的人格卡，卡片驱动分享、收集与回流。

项目由三层构成：**入口产品**（门厅与特异点世界观）、**生产能力**（Agent-first 3D 引擎，按 harness 思路建设）、**留存机制**（人格卡经济与三方闭环）。本计划书论证：这三层合起来，能把盐选的文本库存，转化为知乎可持续的内容体验资产与用户留存资产。

## 一、问题与机会

1. **脑补无法交付。** 阅读体验依赖读者想象：画面在脑子里长出来，但模糊、无法验证、无法分享。读者与故事之间，永远隔着一层想象。
2. **文本内容是一次性消费。** 读完、点赞、离开——盐选沉淀了中文互联网最好的短故事库存，体验却止于首读，平台难以获得持续留存。
3. **传统改编是重资产。** 影视化、游戏化改编的成本决定了只有头部 IP 轮得到，盐选中腰部故事的体验价值长期闲置。

**机会**：AI Agent 的生产能力，第一次让「单篇故事 → 可玩世界」的边际成本趋零。谁能把这条路线的质量底线和世界观包装做扎实，谁就能把盐选库存变成一个新的内容品类。

## 二、产品形态

### 2.1 门厅：2.5 次元的入口中枢

玩家不是用户，是**穿越者**；刘看山不是主角，是**系统助手**——开门、引路、记录、发卡。每一篇盐选故事的开放篇章，是一个等待解决与记录的**特异点**。门厅统一了入口、视觉语言与世界观，让不同的故事体验属于同一个产品。

### 2.2 门后世界：两种来历

| 路线 | 案例 | 定位 |
|---|---|---|
| 手工打磨的玩法实验 | 《蓝血》（ARG） | 把知乎的提问、回帖、评论区做成玩法本身；AI 只在台前接住追问，事实永远来自剧本，零编造 |
| Agent 引擎量产的 3D 世界 | 《近视眼勇闯恐怖游戏》《端妃黑又壮》，及门厅本身 | 把角色的处境变成玩家的处境：近视成为视野限制，庭院日常成为可执行动作 |

统一的只是入口，区别在门后的动作。每条故事交出它独有的东西，变成玩家独有的体验。

### 2.3 人格卡：体验的带走物与回流器

玩完不是结束。系统助手刘看山发给玩家一张人格卡——记录的不是分数，是「我怎样进去过」。

- **分享**：卡片作为媒介，分享朋友邀请做「小测试」——「换作是你，会是哪种人格？」
- **收集**：激发收集癖，建立成就系统（设计中）；每张卡都能带回一个新穿越者
- **回流**：扫码回到同一个门厅入口，不带存档、不剧透，朋友选择自己的门

### 2.4 内容立场（不可让渡的设计原则）

故事属于作者，体验属于你：零编造、不剧透、不替作者写后续；每扇门在原文开放篇章的截断点停下，结局一律引流阅读原文。互动不替代阅读，它让下一次阅读多一段自己的经历。

## 三、生产能力：引擎即 Harness

我们的引擎不是「让 AI 生成游戏」，而是按 **harness** 的思路，给 AI 搭一个能把活干完的环境：

- **现场 ›** 引擎——Agent 干活的地方（模型制作、场景摆放、工程存档与恢复）
- **手册 ›** Skills——它做事的方法（故事理解、边界标注、玩法蓝图、装配规范）
- **验收 ›** 运行验证——活干完必须自己跑一遍。**窄门测试**：门太窄、角色被卡住，Agent 自己查碰撞、改参数、重放，确认通过才算交付。生成成功 ≠ 作品完成。

**审美容错**：PS1 风格是同一思路的审美层——AI 做不出 3A，但 AI 做的 PS1，看起来就该是这样。风格即容错。

**规模化论点**：三扇门是展品，三百扇门才是答案。门厅、《近视眼》《端妃》已由 Agent 搭建完成（30 秒搭建实录可查证），改编的边际成本趋零。

## 四、商业模式与生态闭环

### 4.1 三方闭环

```
作者创作 → 平台采纳（授权改编） → 作者获益（阅读转化与激励）
        → 读者被福利吸引 → 留下使用 → 平台收益 → 再激励作者
```

人格卡是这个闭环的流通媒介：它同时是体验证明、分享物料、收集对象与（设计中的）权益凭证。

### 4.2 卡片经济（分层状态）

- **已上线可玩**：人格卡生成、八种调查人格（《蓝血》）、扫码回流门厅
- **设计中**：收集图鉴与成就系统；卡片转换为兑换货币，兑换盐选会员、福利等实际权益

### 4.3 为什么这能留住人（蚂蚁森林类比）

蚂蚁森林证明：当参与行为同时产生个人成就、社交货币与真实权益时，用户会长期回来。看山任意门的对应结构是——亲历（个人成就）→ 人格卡（社交货币）→ 盐选会员与福利（真实权益）。玩的不只是游戏，各方都能获益，才有持久用户。

### 4.4 平台侧价值

- **效率**：盐选库存从文本资产变成可进入的世界，改编边际成本趋零
- **体验**：读者带着自己的站位回到原文和讨论，阅读与讨论互相引流
- **质量**：零编造、不剧透、来源边界可审阅，结局一律引流原文
- **留存**：收集与权益机制把一次性体验变成长期关系

### 4.5 成本自律

设计中的机制（兑换、成就系统）不纳入本次完成度承诺；它们的价值是证明闭环逻辑成立。落地时的兑换预算，本质是平台既有获客成本的重新分配——从广告投放换成内容互动，一份预算同时买到留存与内容生产。

## 五、目标用户与冷启动

- **核心用户**：盐选核心读者中爱悬疑、爱考据、爱脑洞的年轻用户；剧本杀与互动叙事玩家；热衷心理测试与分享卡片的社交人群
- **冷启动路径**：不靠买量。每张人格卡都是一个入口——「我做了选择 → 卡像我 → 朋友扫码 → 刘看山再开一扇门」。分享即获客
- **平台内承接**：结局引流原文、讨论区回流，体验在知乎生态内闭环，不外溢

## 六、竞争与差异

「故事转游戏」赛道的常见形态是文本分支、2D 视觉小说或 AI 续写。看山任意门的差异在四点：

1. **可进入的 3D 世界第一人称感知**——不是读选项，是亲自站进走廊和庭院
2. **不改写故事，只交付体验**——决策密度按故事需要分配，内容立场保守而清晰
3. **门厅统一世界观**——穿越者 × 系统助手 × 特异点，让散装 demo 成为一个产品
4. **引擎可规模化**——harness 保证及格线，让「三百扇门」成为可讨论的命题
