# 决赛讲稿 · 完整最终版

总时长 ≈ **4 分 57**（讲话 ~3 分 40 + 视频 1 分 47）。
原则：屏幕上的字让评委自己读，嘴只干三件事——讲故事、给理由、指方向。

---

## P1 · 封面（~22 秒）

> 读小说的时候，每个人都在干一件事：脑补。文字停在那里，画面在脑子里长出来——走廊有多暗，那个人站在哪儿。
>
> 但脑补有两个遗憾：它是模糊的，而且，只有你自己看得见。
>
> 《看山任意门》，就是把这段脑补直接做出来——让你亲眼看见，亲自走进去。

（"走进去"一落，**立刻翻页，什么都别说**——门会自己开，白场过后视频自动开始。这段沉默就是开场。）

## P2 · 视频 A（77 秒，闭嘴）

站定，一个字都不讲。

## P3 · 三扇门（~26 秒）

> 刚才你们看到的，不是一个游戏的三关，是三扇门。《蓝血》取的是"众说纷纭"，《近视眼》取的是"看不清"，《端妃》取的是"过日子"——每个故事，交出它独有的东西，变成玩家独有的动作。
>
> 这三扇门，有两种来历：一扇，是我们手工打磨的玩法实验；另外两扇，连同你们刚才的那个门厅，都是一个 Agent 搭出来的。哪扇是哪扇——

（破折号停在半句，直接翻页）

## P4 · AI 分工（~58 秒：视频 30 秒边播边讲 + 收尾 28 秒）

翻页视频自动开播，直接开口：

> 这段画面里，没有人类。空地、平台升起、门框入场、世界就位——选素材、摆位置、拼场景，每个决定都是 Agent 自己做的，人没有碰鼠标。

（说完停两秒，让画面自己跑。视频快完时接：）

> 答案揭晓：刚才搭起来的，就是你们一进门的那个门厅；《近视眼》《端妃》，都是这么来的。
>
> 而《蓝血》不一样——它是手工打磨的玩法实验，AI 只在台前做一件事：接住你的每句追问，但事实永远来自剧本，零编造。
>
> Agent 干活分三份工（抬手指屏幕三行），我只强调质检：不只把世界造出来，还要自己跑一遍。生成成功，不等于作品完成。

## P5 · 引擎 = HARNESS（~42 秒）

> 很多人会担心：AI 做的游戏，能玩吗？我们的回答是：不指望 AI 一次做对，而是给它一个能把活干完的环境。这个东西叫 harness——屏幕上这三行就是它的全部：一个干活的地方，一本做事的手册，一道自己验收的程序。
>
> 举个真实案例：窄门测试。门太窄，角色被卡住，Agent 自己发现、自己修好，再让角色走一遍——确认通过，才算交付。
>
> 所以我们敢说：不敢说神作，保证及格。三扇门只是展品——盐选有那么多故事，**三百扇门，才是答案。**

## P6 · 人格卡 + 门厅经济（~50 秒）

> 玩完，不是结束。你出来以后，刘看山会发你一张卡——它不是战绩截图，记的是你怎么做的选择。脑补原来没法给别人看，现在可以了：你会愿意发给朋友，因为他看到会问——换作是我，会是哪种人格？他扫码进来，自己走一遍，上面这条链就转起来了。
>
> 下面三行我只讲逻辑：卡片让人想分享、想收集；收集沉淀成权益，权益把人留下——作者获益，读者回来，平台收益。像蚂蚁森林，每一方都有理由留下来。
>
> 话说清楚：卡片和回流，今天就能玩；兑换和成就系统，在设计中。设计中的东西不拿来挣分——它只回答一个问题：知乎为什么要做。

## P7 · 收尾（~20 秒）

> 完成度，五个数字就在屏幕上。只有一句要补：那条链接，现在就能点开。未来的三件事，也写在上面。
>
> 最后——谢邀，人在现场。这句话是知乎答主的开场白；今天，它是每一位玩家的状态。谢谢。

## Q&A 一句话卡

- **引擎是不是模板套壳？** → 蓝图按故事生成，同一底座长出不同动作：《近视眼》的失焦和《端妃》的庭院，机制完全不一样
- **AI 到底做了什么？** → 生产（搭建世界）、质检（运行验证）、台前（NPC 表达层）三份工；创意与内容立场是人的
- **零编造怎么保证？** → 事实全部来自剧本结构化数据，LLM 只做表达层改写，出戏自动回退剧本台词
- **为什么 PS1？** → 审美容错：AI 做不出 3A，但 AI 做的 PS1 看起来就该是这样
- **和别家故事转游戏的差异？** → 可进入的 3D 第一人称感知 + 不改写故事只交付体验 + 门厅统一世界观 + 引擎可规模化
- **授权边界？** → 只改编授权池开放篇章，截断点停下，结局一律引流原文
- **数据真实性？** → 31 幕/19 图/3 结局都是实机可玩的，那条链接现在就能点开
- **《蓝血》为什么不交给引擎做？** → ARG 的机关密度和叙事精度目前手工打磨才够格；引擎面向 3D 世界，两条路线共用同一个门厅
- **玩家能做的好像不多？** → 刻意的。故事属于作者，体验属于你；决策密度按故事需要分配，卡片记录的是你怎样进去过
- **兑换谁买单？** → 会员权益是平台既有获客成本，从广告换成内容互动，一份预算买两样
- **防羊毛？** → 兑换挂钩「完成体验并回到原文」的行为，不挂钩刷卡数量
- **作者怎么获益？** → 授权改编 + 结局引流原文的真实阅读转化；分成激励是平台的商业设计
- **成就系统是什么？** → 门厅收集图鉴，集齐解锁称号，服务收集欲，不做数值强度
