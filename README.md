## 一句话

读小说时，人人都在脑补——画面在脑子里长出来，但它是模糊的，而且只有你自己看得见。
看山任意门把这段脑补直接做出来：**让你亲眼看见，亲自走进去。**

## 产品是什么

**门厅**是 2.5 次元的入口空间：你是穿越者，刘看山是你的系统助手；每篇盐选开放篇章，都是一个等待解决与记录的**特异点**。

门后有三扇门，两种来历：

| 门 | 来历 | 体验 |
|---|---|---|
| 《蓝血》 | 手工打磨的玩法实验（ARG） | 把知乎的提问、回帖、评论区，做成玩法本身 |
| 《近视眼勇闯恐怖游戏》 | Agent 引擎搭建（3D） | 角色的近视，变成你的视野限制 |
| 《端妃黑又壮》 | Agent 引擎搭建（3D） | 翻土、播种、洗手、下棋——把日子过稳，也是玩法 |

门厅本身，同样由 Agent 搭建。统一的只是入口，区别在门后的动作。

**人格卡**：玩完带走的不是答案，是「我怎样进去过」。卡片可以分享给朋友做「小测试」，激发收集癖，建立成就系统；扫码回流门厅，朋友再选择自己的门。卡片兑换货币、兑换盐选会员与福利的机制在设计中（见商业计划书）。

## 引擎 = Harness

不指望 AI 一次做对，而是给它一个能把活干完的环境：

- **现场** › 引擎——Agent 干活的地方
- **手册** › Skills——它做事的方法
- **验收** › 运行验证——窄门测试：门太窄、角色被卡住，Agent 自己查碰撞、改参数、重放，确认通过才算交付

不敢说神作，保证及格。PS1 风格是同一思路的审美容错：AI 做不出 3A，但 AI 做的 PS1，看起来就该是这样。

**三扇门是展品，三百扇门才是答案。**

## 内容立场

故事属于作者，体验属于你。零编造、不剧透、不替作者写后续；每扇门在原文开放篇章的截断点停下，结局一律引流阅读原文。
